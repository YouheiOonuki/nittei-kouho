▶ 日程調整 候補日ジェネレーターを使う

使い方

  1. 条件：用件、期間、使う曜日、時間帯、候補の数を入れます。
  2. カレンダー：都合の悪い日を押すと NG になり、別の日が選び直されます。
  3. 文面：形式を選び、「すべてコピー」で貼り付けます。
  4. 仮押さえ：「カレンダーに仮押さえ（.ics）」で自分のカレンダーに入れます。
くわしい使い方と「ばらけさせる」
  1. 条件：用件、期間、使う曜日、時間帯、候補の数を入れます。祝日・振替休日は自動で外れます。
  2. カレンダー：条件に合う日の中から、候補が自動で選ばれます（塗りつぶしの日）。都合の悪い日を押すと NG になり、別の日が選び直されます。「候補に入れる／外す」に切り替えると、候補を手で足したり外したりできます。
  3. 文面：メール・チャット、Forms の選択肢、LINE の 3 つの形式から選び、「すべてコピー」で貼り付けます。回答の期限を入れると文面に入ります。
  4. 仮押さえ：「カレンダーに仮押さえ（.ics）」で、候補日を自分のカレンダーに仮の予定として入れられます。

「ばらけさせる」を選ぶと、候補が期間全体に散らばり、同じ週に固まらないように選びます（例：4 週間で 6 候補なら、同じ週は 2 日まで）。週ごとに曜日もずらすので、「毎週月曜は無理」という人にも答えやすくなります。

候補日は何日くらいがよいか

目安は 5〜8 日です。週と曜日を散らすと、少ない候補でも誰かの都合に合いやすくなります。

少なすぎる・多すぎるとき
  • 少なすぎる（2〜3 日）：全員がそろう日が見つからず、もう一度調整し直すことになりがちです。
  • 多すぎる（10 日以上）：答える側が一日ずつ予定を確かめる手間が増え、返事が遅れます。
  • 散らす：同じ週や同じ曜日に固めると、その週に出張がある人や、その曜日に定例がある人が全部 NG になります。
  • 期間が 1 か月なら、週に 1〜2 日ずつ散らすと答えやすくなります。

忙しい人から先に決める「2 段階調整」

役員や取引先など、予定の空きが少ない人がいる会合では、全員に一度に聞くより、忙しい人に先に聞き、残った日で次の人たちに聞くほうが早く決まることがあります。

2 段階調整の手順
  1. 1 段目：多めの候補（6〜8 日）を、忙しい人（またはその秘書）に送ります。
  2. 回答で残った日にチェックを付けます。
  3. 2 段目：残った日だけで、ほかの参加者に聞きます。候補が絞られているので、答えやすくなります。

このツールでは「2 段階で調整する」にチェックを入れると、1 段目の候補から残った日を選び、2 段目の文面をすぐに作れます。

答えやすく、断りやすい依頼文

「ご都合のよい日をすべて」と頼みます。1 日だけ選んでもらうと、全員がそろう日を探せません。

ほかに書くこと
  • 何の会かを最初に書きます（用件の欄が文面に入ります）。
  • 回答の期限を書きます。期限があると返事が早くなり、催促もしやすくなります。
  • 「どの日も難しい場合は、その旨だけ」と一言添えます。全部 NG の人が黙ってしまうのを防げます。
  • LINE やチャットでは、短く、候補を 1 行ずつ並べると読みやすくなります。

よくある質問

祝日はいつの分まで入っていますか？
内閣府が公表している「国民の祝日」の一覧をもとに、画面の上に表示している年の分まで入っています。翌年の祝日は例年 2 月ごろに公表されるので、公表後に追加します。
会社の休みや年末年始は外せますか？
祝日以外の休み（会社の休業日、年末年始、夏休みなど）は入っていません。カレンダーでその日を押して NG にしてください。
Google フォームや Microsoft Forms にはどう貼り付けますか？
形式で「Forms の選択肢」を選び、「すべてコピー」を押します。Google フォームでは、チェックボックスの質問の選択肢の欄に貼り付けると、1 行ずつ別の選択肢になります。
.ics ファイルは何に使いますか？
候補日を、自分のカレンダーに「仮」の予定として入れるためのファイルです。スマートフォンやパソコンのカレンダーのアプリで開くと取り込めます。

ご利用上の注意・データの扱い

  • 祝日の一覧は内閣府の公表をもとにしていますが、送る前に日付と曜日をご確認ください。
  • 入力中の条件（用件、期間、NG の日など）は、この端末のブラウザ（localStorage、キー nittei-kouho_draft）にだけ保存され、外部には送信されません。書き出し・読み込みはこの画面のボタンから。
  • 「この条件を開くリンクをコピー」で作るリンクには、用件や NG の日などの条件が含まれます。リンクを渡した相手には条件が見えます。
バックアップ・共有リンク・.ics・範囲でまとめて NG
  • バックアップ：「ファイルに書き出す」で、入力中の条件（NG の日や手で調整した日を含む）を JSON ファイルにできます。ファイルはこの端末の中で作り、どこにも送信しません。機種変更のときやブラウザのデータを消す前に書き出しておき、新しい端末ではファイルを移して「ファイルから読み込む」を押してください（今の内容はファイルの内容に置き換わります）。
  • 共有リンク：条件は URL の「#」以降に入っているため、リンクを開いても当サイトのサーバーには送信されません。
  • .ics：カレンダー用のファイルは、お使いの端末の中で作って保存します。確定したら、ほかの候補の予定は消してください。
  • 範囲でまとめて：始まりと終わりの 2 回押すだけで続いた日をまとめて NG にできます。
  • Forms：うまく分かれない場合は、1 行ずつ貼り付けてください。

祝日データと確認日

祝日・振替休日・国民の休日は、内閣府「国民の祝日」についての一覧（CSV）をもとにしています。

対応している年
最終確認日
翌年の祝日・入っていない休み

翌年の祝日は、内閣府が例年 2 月ごろに公表します。公表後に追加します。会社や学校の休日、年末年始の休みは入っていません。範囲外の年を含む期間を選ぶと警告を出します。
